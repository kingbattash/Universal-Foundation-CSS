# Community code of conduct

We welcome contributors with different levels of experience, backgrounds, languages and ideas.

Please communicate respectfully. Critique code and design proposals rather than people. Avoid harassment, personal attacks, discriminatory conduct, spam and sharing anyone's private information without consent.

Maintainers may edit or remove abusive contributions and restrict participation to protect the community. Report concerns privately through the maintainer's GitHub profile or repository moderation channels. Reports will be handled with discretion, consistent with GitHub's community standards.
